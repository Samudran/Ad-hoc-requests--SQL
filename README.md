# 🧮 AtliQ Hardwares - SQL Challenge (Ad Hoc Requests)

This project simulates a hiring challenge by **AtliQ Hardwares**, a leading computer hardware producer in India. The task was to solve 10 real-world business problems using SQL, reflecting the kind of ad-hoc requests junior data analysts often receive.

---

## 🧠 Problem Statement

AtliQ Hardwares' management lacks quick access to data-driven insights for smart decision-making. To improve their analytics capabilities, they planned to hire new data analysts through a SQL challenge designed by their Director of Data Analytics, Tony Sharma.

---

## 🎯 Objective

Acting as a candidate for the role, the objective was to:
- Solve **10 business-driven ad-hoc requests** using SQL.
- Extract meaningful insights directly from the database.
- Present results in a **clear, management-friendly format**.

---

## 🔧 Tools Used

- SQL (MySQL)
- Basic dashboarding tool (Power BI, Excel)

---

## ✅ Approach

1. Analyzed each business request from the provided `ad-hoc-requests.pdf`.
2. Wrote optimized SQL queries to extract the required insights.
3. Summarized results in a basic dashboard for the management.
4. Focused primarily on **SQL logic and query formulation**.

---

## 📌 Notes

- The primary focus of this project was SQL, not dashboarding.
- Dashboard created was **minimal**, intended only to visualize final insights.
- All 10 queries and their corresponding results are available in the SQL Queries file.
